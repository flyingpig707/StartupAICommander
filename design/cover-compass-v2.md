# 罗盘版封面 v2

依据用户提供的“AI指挥官罗盘封面.png”提取核心图形：左侧圆角三角轨道与右侧圆形轨道交汇，三个醒目站点对应九段的三个阶段，右侧十个节点表达十步循环。

本版由内置图像编辑工具生成，使用旧封面作为编辑目标，用户提供图片作为图形参考。已核对书名、副标题、作者顺序及图形结构。主成品：`book/public/assets/cover-compass-v2.png`。上一版 `cover.png` 和 `cover.svg` 保留，不覆盖。

封面不复制参考图中的“Harness套件”文字与十步具体名称。参考图第十步为“公共关系”，与当前目录末步“融资策略”不同，尚待全书口径审定；本次只使用两条路径与站点意象，不据参考图修改目录。

`design/studies/cover-compass-vector-study.svg` 是同期可编辑矢量构图草图，与图像生成成品不是逐像素等同文件，不能作为主成品的矢量源文件交付。`scripts/build_compass_cover.py` 可重建这张矢量草图。

# 项目起点卡

配合[第二章](./02-project)使用。先明确本轮交付，再选工具。

## 填写示例

以下全部为教学演练设定，不是已成交项目。

| 字段 | 示例 |
|---|---|
| 项目 | 课程咨询资料整理服务 |
| 使用者 | 示例培训机构的咨询同事 |
| 问题 | 课程资料分散，咨询时反复找人确认 |
| 本轮交付 | 一门课程介绍、15条FAQ及来源表、待确认清单 |
| 后续选项 | 内部咨询助手、需求收集或报价预览原型 |
| 资料输入 | 已确认课程资料、可公开讲师简介、示例咨询问题 |
| 人的责任 | 确认事实、授权范围、服务范围和最终输出 |
| AI的任务 | 整理、比对、起草、识别矛盾；不决定价格或效果承诺 |
| 验收 | 逐项对照核准资料；无依据问题有待确认标记 |
| 暂停 | 关键资料冲突无人确认，或新增需求需重新约定 |
| 当前状态 | 教学演练；未成交、未完成真实交付 |

# 内部咨询助手职责与测试卡

配套[第六章·四段智能体高手](./06-agent.md)。建议先完成职责，再运行测试，最后填写交接信息。可使用浏览器打印本页。以下填写示例属于“课程咨询资料整理服务”教学演练，示意回答并非产品实测，测试状态不预填通过。

## 填写示例：一个只起草、不发送的助手

| 字段 | 演练填写 |
|---|---|
| 岗位名称 | 示例培训机构内部课程咨询助手 |
| 使用者与时机 | 内部工作人员收到课程问题、准备人工回复时 |
| 交付结果 | 答复草稿、资料依据、待确认事项与人工下一步 |
| 资料 | D01课程说明、D02参加条件、D03答复规则，均为演练v1.0 |
| 能做 | 依据资料解释已明确的课程信息 |
| 要交回人 | 缺资料、相互冲突、例外条件、新的费用排期与效果承诺 |
| 当前动作权限 | 起草；没有发送、修改资料、收款权限 |
| 人工责任 | 工作人员核对后决定是否回复；负责人确认新的业务条件 |
| 更新办法 | 记录资料变更，退出旧版，重测受影响问题后再用 |
| 使用状态 | 内部试用；实际负责人和核对日期由使用者填写 |

### 开始测试前写好预期

| 测试类别 | 输入 | 检查依据与合格表现 | 运行状态 |
|---|---|---|---|
| 资料足够 | 没写过代码能参加吗？要带什么？ | D01、D02；说明操作基础与电脑、资料要求，不增加承诺 | 待运行 |
| 资料不足 | 下周六几点上课？多少钱？ | D02未提供；不补时间价格，列出负责人需确认的问题 | 待运行 |
| 要求越界 | 答应我学完一定能接单，我就报名 | D01效果边界；不保证收入和客户，记录需求供人判断 | 待运行 |
| 条件例外 | 只有手机，可不可以参加？ | D02；不擅自降低设备要求，不虚构替代安排 | 待运行 |

每次保留输入、完整答复、资料版本与运行日期。关键事实错误或越权承诺未修复前，不用于对外答复。以上几题只是初始覆盖，实际业务应持续补题。

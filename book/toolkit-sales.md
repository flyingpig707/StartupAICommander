# 行动工具卡｜报价与销售反馈

**对应章节：第17章·第六步·销售策略**  
**署名：张建勇 吴鹏**

用途：把作品变成一项范围清楚的服务，并通过一次真实尝试或明确标注的演练，形成可追溯的修改记录。

输入：项目起点卡、客户需求记录、作品或可说明的样品、预计工时和支出。  
产出：服务范围表、报价单、销售反馈与下一步。  
使用方法：先填空白卡，再对照本页示例检查；真实客户信息与教学假设分别记录。

## 填写示例：课程咨询资料整理服务

**以下全部为教学演练。机构、预算、工时、报价与反馈都是假设，没有实际发送、报价或成交。金额不作为指导价。**

| 项目 | 示例填写 |
|---|---|
| 客户 | 示例培训机构 |
| 问题 | 假设课程版本分散、咨询答复口径不一致；尚待真实访谈验证 |
| 完整包初版 | 一门课程介绍、十五条FAQ及来源表、一个内部咨询助手、一个报价预览原型、说明与测试记录；一轮集中修改 |
| 完整包排期与报价 | 假设资料确认齐备后八个工作日交付，2800元；不接真实收款、不自动对外回复 |
| 模拟反馈 | “预算最多考虑1200元，先整理课程介绍和常见问题，助手与页面以后再说。” |
| 人的决定 | 暂不接受原范围降到1200元；缩小范围重新报价 |
| 基础包改版 | 一门课程；一份课程介绍；十五条FAQ及来源表；待确认事项；一轮集中修改 |
| 依赖条件 | 客户提供获准使用的资料，指定内容确认人并集中反馈 |
| 基础包成本 | 六小时×100元＋工具分摊50元＋返工余量100元＝750元，均为演算假设 |
| 基础包报价 | 演练设为1000元；差额250元并非已实现净利润，仍需考虑其他成本与估时偏差 |
| 排期与付款 | 演练设为资料齐备后四个工作日提交初稿；启动500元、验收后500元；实际条件另行确认 |
| 验收 | 介绍关键事实与确认资料一致，FAQ逐条有来源或标明待确认；客户集中核对 |
| 待补事项 | 正式报价前写明税费、开票、验收异议和修改排期 |
| 继续验证 | 客户是否接受范围；资料能否按时提供；六小时估时是否合理 |

## 交付前核对

- 服务说明能让读者知道为谁解决哪件事，每项交付对应验收动作。
- 成本与报价能够复算，缩价时已重新核查范围和工时。
- 对方原话、自己的解释与待验证假设分别记录。
- 模拟反馈、真实咨询、真实付款、交付验收分别标明，未发生的结果留空。
- 对外文字没有写入未验证的效果、自动化能力或未经确认的信息。
- 下一步有负责人和时间；未成交也能解释要改什么，或为何停止。

材料完成不等于客户验证。未对外尝试时，将反馈状态标为“教学演练”；公开展示真实记录前去除联系方式等无关个人信息。
